1. One-paragraph summary

Recent papers (Bui et al. 2605.09649, CapKV 2604.25975, IndexMem 2605.25475) show that evicting tokens from the KV cache of a long-context LLM can exceed full-cache accuracy, because irrelevant tokens dilute attention. Those papers report the effect averaged over benchmarks where it occurs. This project answers the two questions they leave open: (Q1) on which tasks does eviction help and on which does it hurt, and (Q2) can we tell in advance, per input, without labels or training? We find a clean binary partition on RULER: five task families (multi-hop variable tracking, aggregation, single/multi-doc QA, multi-value retrieval) are dilution-prone (eviction helps), while precise multi-needle retrieval (NIAH-MultiKey-3) is capacity-bound (eviction is monotone damaging) — with zero counter-examples across every model, size, and context length tested. A cheap statistic on prefill attention (the early-to-late head-agreement drop) predicts the partition per input, label-free. Wrapping any existing evictor in a one-line gate on this statistic lifts all 16 (model × base evictor) cells tested, by a grand mean of +22.7pp at matched budget, with a single threshold and no per-method tuning.

2. Background and motivation

Long-context LLM inference is dominated by the KV cache: memory grows linearly with context, and decode is memory-bandwidth-bound. KV-cache eviction methods (SnapKV, H2O, StreamingLLM, PyramidKV, …) keep only a budgeted fraction b of cached tokens. The classical framing treats full cache as the accuracy ceiling and eviction as a controlled loss.

That framing broke in early 2026. Several groups showed eviction can beat the full cache: removing irrelevant tokens removes the attention mass they steal from relevant ones (“attention dilution”). But all of these results are benchmark averages on suites where the effect happens to occur. Averages hide a dangerous failure mode: on some task types, eviction is catastrophic (accuracy 99% → 0%). Nobody had characterized which tasks fall on which side, or given a way to detect the side per input at inference time.

The project's pre-registered hypothesis test uses the per-input recovery rate ρKV := the fraction of inputs where some budget b < 1 gives strictly higher accuracy than the full cache (threshold ρ ≥ 0.05, committed before any sweeps ran). This per-input metric is stricter and less noisy than the mean-accuracy curves used by prior work.

3. The three contributions

  1. An empirical task-type partition. Dilution-prone tasks (eviction helps a non-trivial input fraction) vs capacity-bound tasks (eviction only hurts). Universal across 4 model sizes (1.5B–14B), multiple architectures (Qwen2.5, Mistral, plus Llama-3.1-8B / Yi-1.5-9B with partial transfer), and both 4K and 16K contexts. Zero counter-examples in the core Qwen/Mistral cells.
  2. A label-free a priori predictor. The head-agreement drop: mean Jaccard top-32 agreement between attention heads, measured in early-third layers minus late-third layers of the prefill. Large drop ⇒ heads diverge late ⇒ integration-breadth task ⇒ dilution-prone. Small/negative drop ⇒ heads converge on one needle ⇒ capacity-bound. No labels, no training, no extra forward pass.
  3. A training-free gating wrapper. One conditional turns the predictor into a method: if the drop ≥ τ, apply the base evictor; otherwise keep the full cache. It is orthogonal to the choice of base evictor and lifts every one tested, including a trained evictor (Bui's DBTrimKV: +23.3pp) and a closed-form one (CapKV proxy: +1.5pp on LongBench qasper).
gated_eviction(prompt, base_evictor, τ):
    cache = prefill(prompt)
    drop  = head_agreement_drop(cache.attentions)   # early-third − late-third mean Jaccard(top-32)
    if drop ≥ τ:  return base_evictor.evict(cache)   # dilution-prone: evict (it helps)
    else:          return cache                       # capacity-bound: keep full KV

Three properties make the partition more than a benchmark curiosity:

  • It amplifies with context length on dilution-prone tasks (VT: 0.06 → 0.19 going 4K → 16K). Longer context = more dilution = more for eviction to remove.
  • It interacts with model size exactly as the theory predicts. Qwen-3B saturates the 4K tasks (no headroom, ρ ≈ 0) but re-enters the dilution regime at 16K (FWE ρ = 0.32, the largest measured).
  • It is causal, not correlational. A controlled distractor sweep (niah_multikey_1/2/3) shows the predictor statistic shrinking monotonically (0.155 → 0.045) as distractor count grows, with non-overlapping per-input ranges between MK2 and MK3.

5. Result 2: the label-free predictor

Two simple candidates fail: mean attention entropy does not separate the tasks (0.31–0.35 everywhere), and mean head agreement ties VT with NIAH-MK3. The statistic that works is depth-conditional: the change in head agreement from early to late layers.

Intuition. In capacity-bound tasks, late layers converge: every head locks onto the same few needle positions, so head agreement stays high. In dilution-prone tasks, late layers integrate: heads fan out across different parts of the answer structure, so agreement drops. The size of the drop measures integration breadth, which is exactly what determines whether there is dilution to remove.

7. Theory: mechanism and scaling formula

The mechanism section (in theory_h3.md) models a head's output as signal + noise over relevant positions R and distractors N. Three propositions, with the dilution mechanism itself credited to Bui et al. (Prop. 3.1/Cor. 3.2), since they published it first:

  • Prop. 1 (SNR improvement). Under a good-scoring evictor, post-eviction SNR improves by a factor ≥ ρR² · |N| / |kept distractors|; renormalization cancels in the SNR.
  • Prop. 2 (partition). Inputs with diffuse attention (αR ≪ 1) gain SNR from eviction; inputs with concentrated attention (αR → 1) can only lose. This is the dilution-prone / capacity-bound split.
  • Prop. 3 (context-length amplification). Combining headroom and SNR gain yields the scaling formula
    ρKV ≈ (1 − Afull(M, T)) · precov(ρR/γ).

One formula explains three separately observed phenomena:

  1. Context amplification: VT ρ grows 0.06 → 0.19 as headroom grows 0.18 → 0.75 (4K → 16K).
  2. Model-size saturation: Qwen-3B at 4K has Afull ≈ 1, so ρ ≈ 0.
  3. Regime re-entry: the same Qwen-3B at 16K regains headroom and shows the largest ρ measured (FWE 0.32).

10. Limitations and open problems

  • Cross-architecture predictor transfer is partial. The drop ordering transfers across Qwen and Mistral with one threshold, but Llama-family models (SmolLM2, Llama-3.1-8B, Yi-1.5-9B) misrank niah_multivalue. An architecture-normalized variant of the statistic is the open theoretical step, deferred to follow-up.
  • One calibration failure cell documented. Qwen-3B at 16K compresses all drops below the fixed τ; the 40-input recipe fixes it, but it shows the absolute threshold is not (model × context)-invariant. The ordering is.
  • H2O at 14B degrades to SnapKV under the two-pass long-context scoring (documented honestly; it inflates nothing, the Δ is real but the baseline identity blurs).
  • PyramidKV is a depth-weighted variant, not strict per-layer budgets (HF cache-shape constraint).
  • English-only RULER; models ≤ 14B; contexts ≤ 16K. LongBench cross-benchmark sweeps are running; a 32K row and a joules/token table (A100, possibly Jetson Orin) are stretch goals.

Reproducibility notes

  • RoPE-correct eviction. HF transformers silently re-derives position_ids from the attention mask via cumsum, which shifts RoPE for evicted positions. All sweeps use cache slicing with explicit position_ids. A budget=1.0 audit confirms the pipeline matches clean prefill-decode.
  • Long-context attention harvesting. Eager attention with output_attentions=True OOMs at 16K; the code uses SDPA prefill plus a small eager second pass over the last 32 queries.
  • Protection protocol. All evictors keep 4 sink tokens + 32 recent tokens, so the partition is a finding beyond Garcia-style structural protection.
  • Hardware. Everything runs on the lab's 4× A100-80GB; the largest model is 14B.
